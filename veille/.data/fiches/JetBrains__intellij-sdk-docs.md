# JetBrains/intellij-sdk-docs

> Sources de la documentation du SDK de la plateforme IntelliJ, pour auteurs de plugins.

## Le problème
Les développeurs de plugins pour les IDE JetBrains ont besoin d'une documentation de référence.

## Ce que ça fait vraiment
Le dépôt héberge le site de documentation du SDK ; le README, très court, renvoie aux exemples de code (dépôt miroir) et aux canaux de retour d'erreurs. Rien d'autre n'est décrit.

## Comment c'est branché
Matière insuffisante pour un schéma : le README ne décrit aucune architecture.

## Essayer
Aucune commande documentée : lire le site publié.

## Coût et pièges
Gratuit. README sous 800 caractères : la fiche reste minimale.

## Ce que ce n'est pas
Pas le SDK lui-même ni un plugin : uniquement la documentation.

## Alternatives
Aucune alternative nommée dans le README.

## Pour toi
À ignorer : utile seulement si tu écris des plugins pour un IDE JetBrains.

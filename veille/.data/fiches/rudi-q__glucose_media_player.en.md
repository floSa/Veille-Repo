# rudi-q/glucose_media_player

> Windows desktop video and audio player that generates and translates subtitles locally with Whisper.

## The problem
Missing or badly timed subtitles, and transcription services that send your files to the cloud.

## What it actually does
Live subtitles generated by Whisper on your PC a few minutes ahead, local translation, transcription of an entire video, subtitle positioning that avoids faces. A Features tab tests CPU, memory and graphics to tell what will run well. Player with gallery, picture-in-picture and varied formats. Built with Rust and Tauri.

## Trying it
Download the Windows installer from the Releases page, then drag a file into the window. No command line is documented.

## Cost and gotchas
Free; models are downloaded once. The README only mentions Windows. Heavy features require a sufficiently powerful PC.

## What it is not
Not a reusable transcription library: it is an application. The README says "zero telemetry" but does not detail what is measured.

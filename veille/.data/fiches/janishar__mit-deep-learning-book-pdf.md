# janishar/mit-deep-learning-book-pdf

> Version PDF, complète et par chapitres, du livre Deep Learning de Goodfellow, Bengio et Courville.

## Le problème
Le livre de référence n'est proposé qu'en HTML sur son site, ce qui gêne la lecture hors ligne.

## Ce que ça fait vraiment
Le dépôt contient des PDF réalisés à partir d'impressions du contenu HTML : le livre entier et un PDF par chapitre. Le README ajoute des liens vers exercices, diapositives et ressources externes, et une publicité pour un modèle de projet data de l'auteur.

## Comment c'est branché
Pas de diagramme : c'est un dépôt de fichiers PDF. Non documenté.

## Essayer
Aucune commande documentée : télécharger les PDF depuis le dépôt.

## Coût et pièges
Gratuit. L'auteur du dépôt invite à acheter le livre (72 dollars selon le README).

## Ce que ce n'est pas
Pas une source officielle : c'est une copie reconstituée par un tiers, sans licence déclarée. Le livre est lisible gratuitement sur deeplearningbook.org.

## Alternatives
- http://www.deeplearningbook.org/ : version officielle en ligne, à privilégier.

## Pour toi
À ignorer : préfère le site officiel du livre, plutôt qu'une copie PDF sans licence déclarée.

# ROCKNIX/distribution

> Distribution Linux immuable pour consoles de jeu portables, développée par une petite communauté.

## Le problème
Les consoles portables ont besoin d'un système tout prêt pour l'émulation, la batterie et les manettes.

## Ce que ça fait vraiment
Système Linux immuable avec jeu réseau local et distant, tactile, réglages batterie/performance, musique et vidéo, Bluetooth, sortie HDMI, synchronisation (Syncthing, rclone), VPN (Wireguard, Tailscale, ZeroTier), scraping et RetroAchievements. Logiciels originaux sous GPL v2 ; les composants intégrés gardent leur licence.

## Comment c'est branché
Matière insuffisante pour un schéma fidèle : aucune architecture fournie ; le README ne décrit que les fonctions.

## Essayer
Aucune commande documentée dans le README.

## Coût et pièges
Gratuit. Compatibilité selon appareil non précisée dans le README.

## Ce que ce n'est pas
Pas un système généraliste : il vise les consoles portables.

## Alternatives
Aucune alternative nommée dans le README (JELOS et CoreELEC sont cités comme sources d'inspiration).

## Pour toi
À ignorer : système pour consoles de jeu, hors data/IA/MLOps.

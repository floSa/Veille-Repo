# journey-ad/gemini-watermark-remover

> Local tool that removes the visible watermark from Gemini-generated images and videos: website, extension, CLI.

## The problem
Images generated by Gemini carry a semi-transparent logo at the bottom right, which people sometimes want to remove without sloppy retouching.

## What it actually does
- Inverts the logo's alpha compositing ("reverse alpha blending" formula) instead of an AI fill, with calibrated masks.
- Detects the watermark's size and position via a catalog of Gemini output sizes, then a local search and a validation.
- Shipped as a userscript, Chrome extension, CLI (`gwr remove`), JavaScript SDK and agent skill; local processing, no file upload.
- Does not remove invisible marks (SynthID); video mostly goes through the online site.

## How it is wired
```mermaid
flowchart LR
  U[Userscript / Extension] --> P[Page runtime]
  P --> W[watermarkEngine.js]
  C[CLI bin/gwr.mjs] --> W
  W --> A[Embedded alpha maps]
  W --> I[imageProcessing.js]
```

## Trying it
```bash
node bin/gwr.mjs remove <input> --output <file>
pnpm dlx @pilio/gemini-watermark-remover remove <input> --output <file>
pnpm install && pnpm build
```

## Cost and gotchas
Free. The README points to third-party services (online sites, pilio.ai) and asks you to install `sharp` for the CLI.

## What it is not
Not legally harmless: removing a watermark may violate terms of use or the law depending on the country and the use; the README puts responsibility on the user. It does not remove invisible markers.

## Alternatives
Allen Kuo's Gemini Watermark Tool, of which this repository is the JavaScript port.

## For you
Ignore: unrelated to data/AI/MLOps work, and removing provenance marking raises a traceability problem for synthetic content.

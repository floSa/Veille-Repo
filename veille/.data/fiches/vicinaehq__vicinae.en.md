# vicinaehq/vicinae

> Native desktop launcher, compatible with Raycast extensions, for Linux and macOS.

## The problem
Searching applications, files, clipboard or snippets from a single fast, keyboard-driven launcher.

## What it actually does
Native command palette: application search, clipboard history, text expansion, file search, tab switcher, emojis, calculator, windows and fonts. React/TypeScript extensions compatible with Raycast, script commands and dmenu-style menus.

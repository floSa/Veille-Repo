# juliansteenbakker/community_charts

> Fork communautaire de google/charts, bibliothèque de graphiques pour Flutter.

## Le problème
La bibliothèque d'origine de Google n'est plus l'option maintenue par Google pour les graphiques Flutter.

## Ce que ça fait vraiment
Reprend `google/charts`, bibliothèque de graphiques pour l'interface mobile Flutter. Le README ne dit rien de plus : types de graphiques et exemples sont renvoyés à une galerie en ligne. Ce n'est pas un produit officiel Google.

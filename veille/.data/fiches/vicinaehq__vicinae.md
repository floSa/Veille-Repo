# vicinaehq/vicinae

> Lanceur de bureau natif, compatible avec les extensions Raycast, pour Linux et macOS.

## Le problème
Chercher des applications, fichiers, presse-papiers ou snippets depuis un seul lanceur rapide au clavier.

## Ce que ça fait vraiment
Palette de commandes native : recherche d'applications, historique du presse-papiers, expansion de texte, recherche de fichiers, sélecteur d'onglets, émojis, calculatrice, fenêtres et polices. Extensions en React/TypeScript compatibles Raycast, commandes script et menus de type dmenu.

## Essayer
Aucune commande documentée dans le README : la documentation d'installation est sur vicinae.com.

## Coût et pièges
Gratuit. Le README mentionne SoulverCore comme moteur de calcul optionnel sur macOS ; le reste de l'installation est ailleurs.

## Ce que ce n'est pas
Pas un outil de données ni d'IA. Le README ne détaille ni l'installation ni les plateformes.

## Alternatives
Raycast, dont il reprend l'écosystème d'extensions (cité dans le README).

## Pour toi
À ignorer pour ton métier : utilitaire de bureau de confort, sans lien avec data, IA ou MLOps.

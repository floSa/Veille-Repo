# microsoft/Mastering-GitHub-Copilot-for-Paired-Programming

> Microsoft course of about ten hours to learn GitHub Copilot, from agent mode to advanced uses.

## The problem
Copilot is often used as a mere autocomplete, with no method for multi-step tasks or existing projects.

## What it actually does
Offers lessons ranked beginner, intermediate and advanced, each with a text, an exercise and resources. Topics: JavaScript, Python, C#, Copilot CLI, coding agent, MCP, Azure, complex SQL, legacy project migration, data science with notebooks. You fork the repository to do the exercises.

## Trying it
No command documented. Steps: fork the repository, enable Copilot in VS Code, follow the lessons.

## Cost and gotchas
An active GitHub Copilot subscription is required (a free plan is mentioned). A GitHub account is needed for the fork.

## What it is not
Not a tool, nor an open source code assistant product: it is educational content centered on a SaaS. No neutrality toward other assistants.

## Alternatives
No alternative named in the README (a Copilot "Learn Collection" is cited as a follow-up).

## For you
Worth watching: useful to build skills on Copilot and MCP, of no interest if you use another assistant.

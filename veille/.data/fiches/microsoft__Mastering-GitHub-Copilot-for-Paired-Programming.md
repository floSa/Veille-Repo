# microsoft/Mastering-GitHub-Copilot-for-Paired-Programming

> Cours Microsoft d'environ dix heures pour apprendre GitHub Copilot, de l'agent mode aux usages avancés.

## Le problème
Copilot s'utilise souvent comme simple autocomplétion, sans méthode pour les tâches multi-étapes ou les projets existants.

## Ce que ça fait vraiment
Propose des leçons classées débutant, intermédiaire et avancé, chacune avec un texte, un exercice et des ressources. Thèmes : JavaScript, Python, C#, Copilot CLI, coding agent, MCP, Azure, SQL complexe, migration de projet legacy, data science avec notebooks. On forke le dépôt pour faire les exercices.

## Comment c'est branché
```mermaid
flowchart LR
  A[Fork du dépôt] --> B[Leçon README]
  B --> C[Défi à réaliser]
  C --> D[GitHub Copilot dans VS Code]
  D --> E[Ressources complémentaires]
```

## Essayer
Aucune commande documentée. Étapes : forker le dépôt, activer Copilot dans VS Code, suivre les leçons.

## Coût et pièges
Il faut un abonnement GitHub Copilot actif (une formule gratuite est mentionnée). Un compte GitHub est nécessaire pour le fork.

## Ce que ce n'est pas
Pas un outil, ni un produit open source de code assistant : c'est du contenu pédagogique centré sur un SaaS. Pas de neutralité vis-à-vis des autres assistants.

## Alternatives
Aucune alternative nommée dans le README (une « Learn Collection » Copilot est citée en suite).

## Pour toi
À surveiller : utile pour monter en compétence sur Copilot et MCP, sans intérêt si tu utilises un autre assistant.
